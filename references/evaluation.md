# 替換判斷 / Replacement decisions

先確認真正必需的功能；已有情境足夠就不再發問卷。

| Task | Decision boundaries |
|---|---|
| 錄影 / Recording | 麥克風、系統音訊、鏡頭、運鏡、字幕、分享分開 / Separate mic, system audio, webcam, zoom, captions and sharing. |
| 截圖 / Screenshot | 區域、滾動、OCR、標註 / Region, scrolling, OCR and annotation. |
| 語音 / Voice | 即時輸入、檔案轉錄、說話者、TTS 分開 / Dictation, file transcription, diarization and TTS differ. |
| 剪輯 / Editing | 編碼、交付、外掛、團隊 / Test real codecs, delivery formats, plugins and team projects. |
| 文書 / Office | 字型、修訂、巨集、動畫 / Check fonts, tracked changes, macros and animations. |
| PDF | 拆合頁面、改正文、OCR、簽章 / Separate pages, text editing, OCR and signatures. |

Labels: 建議試用 / Try when mandatory needs have supporting documentation; 有條件替換 / Conditional for explicit tradeoffs; 暫不建議 / Keep current tool when a core dependency fails. Unknown remains unknown.

Savings = actual avoidable spending in the next 12 months minus replacement recurring costs and one-time cash transition costs. Request dates, currency, seats and bundles only when calculating. No spending data means “未提供實付費用 / Actual spending not provided”. Nonrefundable prepaid charges are not recoverable savings. Mixed currencies need a stated rate/date or separate totals. Time cost = user-estimated hours × user-provided hourly value, shown separately. CLI does not calculate savings.

Assumptions-only example: cancellable NT$300/month, zero replacement subscription, NT$600 setup → NT$3,000 cash saving. Four hours at NT$500/hour → NT$1,000 after time cost. Keeping a required bundle can reduce avoidable cost to zero.
