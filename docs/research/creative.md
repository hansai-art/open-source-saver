# 創意、工程與科學工具研究批次

新增 38 個獨立候選、11 個主分類、21 組條件式商用工具配對。

所有項目於 2026-09-12 查閱官方網站、官方儲存庫、官方託管頁或官方下載資料。沒有執行軟體、安裝、遷移或繁中品質測試；用途與限制是文檔摘要及待驗證事項。Hugin 官方列有繁體中文，其餘未因多語系宣稱而推定繁中支援。

## 重要區分

- Penpot / GDevelop：開源編輯器或核心不等於所有雲端服務及企業功能免費。
- Ardour：官方預編譯版本付費，原始碼自行建置免費但門檻較高。
- FontForge：整體 GPLv3+，不是把原 BSD 部件授權套到整個成品；Sonic Pi GUI 也有 GPL 相依元件。
- Scribus GitHub 只是社群鏡像；Inkscape 正式程式庫在 GitLab。
- darktable 目前主線 README 列 Mac 為 Apple Silicon / macOS 14+；主線文檔可能含尚未進穩定版內容，因此清單只寫核心用途。
- OpenToonz 官方指定下載來源為 opentoonz.github.io 與其 GitHub，避免同名非官方站。
- Qtractor 只列 Linux；LÖVE / libGDX 標成 engine，避免推薦引擎給只想一鍵安裝的使用者。
- ImageJ 與 Fiji 不重複計數；Sonic Visualiser 不另外灌入其周邊家族工具。
- 沒有引用未知現價、沒有估算未取消的套裝訂閱為已節省。配對僅是工作需求候選，沒有宣稱完整替代。
